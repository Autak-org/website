# Editing the Autak website

**Full user guide (add, edit, delete, photos, troubleshooting):**
[USERGUIDE.md](../USERGUIDE.md)

This folder holds the Markdown files. Always fill in German (`_de`) and English (`_en`).

| What | Folder | Template |
|---|---|---|
| News | [`news/`](news/) | [`news/_template.md`](news/_template.md) |
| Internships / theses | [`positions/`](positions/) | [`positions/_template.md`](positions/_template.md) |
| Shop | [`shop/`](shop/) | [`shop/_template.md`](shop/_template.md) |
| Team / alumni / supporters | [`members/`](members/) | [`members/_template.md`](members/_template.md) |
| Quotes | [`voices/`](voices/) | [`voices/_template.md`](voices/_template.md) |
| Press citations | [`press/`](press/) | [`press/_template.md`](press/_template.md) |
| Videos | [`videos/`](videos/) | [`videos/_template.md`](videos/_template.md) |
| Capabilities | [`capabilities/`](capabilities/) | [`capabilities/_template.md`](capabilities/_template.md) |
| Projects | [`projects/`](projects/) | [`projects/_template/`](projects/_template/) |

Copy a `_template.md` (or the project `_template` folder) to create a new item.
Files and folders that start with `_` do not appear on the site.
